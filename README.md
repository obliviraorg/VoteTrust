## 🧠 What is VoteTrust?

🟦 **VoteTrust** is a small and secure blockchain-based voting system for  
**college / institutional elections**.

It lets users vote, verify their ballot and view live results —  
without revealing who voted for whom.

---

## ✨ Key Features

🟩 Secure blockchain voting  
🟦 Encrypted ballots + IPFS storage  
🟨 Live results & verification  
🟪 Login & voter verification  
🟥 Admin election dashboard  

---
